MULTI-AGENT COLLABORATION

One shared workflow.

Four agent roles coordinate input processing, construction, review and rendering. Select an agent to explore its internal workflow.

REPROCESSING AGENT

Turn evidence into modeling context

Validate assets, align motion conventions when trajectories are present, and parse visual evidence into entities, relations and cameras.

BUILDING AGENT

Construct, compose and animate

Scene planning and refinement lead to robot import, composition and motion validation. Scene and composition reviews feed corrections back to the relevant steps.

RENDERING AGENT

Add appearance, then evaluate

The Proxy Video guides geometry, motion and timing. The reference image and prompt guide appearance. Scores and user feedback support iterative refinement.

REVIEWING AGENT

Inspect evidence and repair locally

Collect visual evidence, revisit numerical and physical evidence in execution logs, and correct localized defects. Preserve the review record and unresolved issues for user feedback.

03 / EVALUATION

How video quality is evaluated

Seven objective metrics measure visual quality and motion. Three vision-language assessments check realism, coherence and task consistency.

01 / Objective metrics

Normalized to 0–100 · higher is better

018.75%

Sharpness

Clarity of image details and edges.

026.25%

Exposure

Penalizes excessively dark or bright pixels.

0312.50%

Color stability

Color consistency between adjacent frames.

048.75%

Temporal flicker

Penalizes abrupt brightness and appearance changes.

0512.50%

Motion smoothness

Continuity of optical flow and motion.

066.25%

Scene stability

Scene consistency without unwanted camera drift.

0745.00%

Action fidelity

Compare motion direction, intensity and timing against the Proxy Video.

Weights follow the current implementation.

02 / Vision-language assessment

Reference + temporal evidence + task

40%

Visual realism

Materials, lighting, shadows, geometry and generation artifacts.

25%

Physical & temporal coherence

Robot structure, contact, spatial relationships and visible continuity.

35%

Task semantic consistency

Target identity, required actions, event order and final state.

Judgments use the reference image, chronological video frames and task instructions.

Combined score · default weights

S = 0.80 Sobj + 0.20 SVLM

An initial objective score below the threshold triggers one automatic correction; videos still below the threshold proceed to human review.

04 / HARNESS & ARCHITECTURE

Every iteration leaves a useful trace.

The task coordination system (left) records execution state, artifacts and stage summaries as evidence for the experience repository (right). The repository reviews reusable rules and returns relevant experience to later Building and Rendering stages, closing the loop from execution records to experience and back to generation.

Keep the current stage, iteration and feedback aligned as agents exchange results.

02 / PRESERVE

Keep the evidence

Continue from recorded state

Recover the task context and intermediate results to review or continue an interrupted workflow.
